## Látka

**Účetní doklady**
- faktury:
  - velkoobchodník (dodavatel) — zboží (cena C) → obchodník (prodejce)
  - obchodník — potvrzení o příjmu zboží → velkoobchodník
  - obchodník — zboží (cena C + obchodní marže) → zákazník (kupec)
  - zákazník — peníze (cena C + obchodní marže) → obchodník
  - obchodník — peníze (cena C) → velkoobchodník
  - velkoobchodník — potvrzení o úhradě zboží → obchodník
- dluh = **závazek** (povinnost zaplatit zboží/službu)
  - dodavatel (**věřitel**, má **pohledávku** = čeká na peníze) — zboží, výrobky (sám vyrobil), služba → odběratel (**dlužník**, má **závazek**)
  - odběratel — peníze → dodavatel

**Účty**
1. věcné (rozvahové: majetek, závazky)
2. výsledkové (náklady, výnosy ⇒ výsledek hospodaření: zisk / ztráta)

**Podvojné účetnictví** — každý účet má dvě strany: **MD** (má dáti) a **D** (dal).

**Účetní výkazy**
1. rozvaha
2. výsledovka
